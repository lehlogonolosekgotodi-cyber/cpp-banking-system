# C++ Banking System

A C++ console-based banking system developed to practice Object-Oriented Programming (OOP) concepts.

## Features

- Create and manage a bank account
- Store account holder information
- Check account balance
- Deposit money
- Withdraw money
- Display account information

## OOP Concepts Used

- Classes and Objects
- Encapsulation
- Private and Public Members
- Constructors
- Member Functions
- Data Abstraction

## Technologies Used

- C++
- Object-Oriented Programming
- Console-based application

## Purpose

This project was created to strengthen my understanding of Object-Oriented Programming in C++ and demonstrate how OOP concepts can be applied to a simple banking system.
